# Calculator

A modern, responsive calculator application with theme switching capability.

## Features

- **Basic Arithmetic Operations**: Addition (+), Subtraction (-), Multiplication (×), Division (÷)
- **Additional Functions**: 
  - Clear All (AC)
  - Delete (DEL) - Remove last digit
  - Percentage (%)
- **Theme Switching**: Toggle between three themes:
  - Default theme (gray/orange)
  - Dark theme (black background)
  - Light theme (blue/green accents)
- **Keyboard Support**: Use your keyboard for faster calculations
- **Responsive Design**: Works on desktop and mobile devices
- **Theme Persistence**: Your theme choice is saved in local storage

## Usage

Simply open `index.html` in a web browser to start using the calculator.

### Keyboard Shortcuts

- **Numbers (0-9)**: Enter numbers
- **Operators (+, -, *, /)**: Perform operations
- **Enter or =**: Calculate result
- **Escape**: Clear all
- **Backspace**: Delete last digit
- **%**: Convert to percentage
- **.**: Decimal point

### Theme Switching

Click the theme toggle button (🌙/☀️/🌓) in the top-right corner to cycle through available themes:
1. Default theme → Dark theme → Light theme → Default theme...
