# Calculator

A Windows calculator application with theme-switching capabilities.

## Features

- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Percentage calculations
- Clear and backspace functions
- Sign toggle (positive/negative)
- **Theme switching**: Switch between Light and Dark themes via the Theme menu

## Requirements

- Python 3.x
- tkinter (usually comes pre-installed with Python)

## Running the Calculator

```bash
python calculator.py
```

## How to Use

1. **Basic Operations**: Click on number buttons and operator buttons to perform calculations
2. **Calculate**: Press the `=` button to see the result
3. **Clear**: Press the `C` button to clear the display
4. **Backspace**: Press the `⌫` button to delete the last character
5. **Toggle Sign**: Press the `±` button to switch between positive and negative
6. **Change Theme**: Go to the `Theme` menu and select either `Light Theme` or `Dark Theme`

## Themes

- **Light Theme**: Classic light background with dark text
- **Dark Theme**: Modern dark background with light text
