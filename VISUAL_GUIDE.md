## Theme Switching Menu

When you click on "Theme" in the menu bar, you'll see:
```
Theme ▼
  ├─ Light Theme
  └─ Dark Theme
```

Click on either option to instantly switch the theme!

## Usage Example

### Example Calculation: 123 + 456 = 579

1. Click buttons: 1 → 2 → 3 → + → 4 → 5 → 6 → =
2. Display shows: 579

### Switching Theme:

1. Click "Theme" menu → Select "Dark Theme"
2. All colors update instantly!
3. Calculator functionality remains the same
4. Switch back to "Light Theme" anytime
